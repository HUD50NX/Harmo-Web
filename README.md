# Harmo Web

Versão do Harmo que roda no navegador (iPhone, Android, PC). Início com **Minhas cifras** e **Teoria**.

- `index.html`, `css/`, `js/` — o app (sem build).
- `ilustrada.html` — Harmonia ilustrada (Círculos, Árvore, Pirâmide, De → Até, Estrelas, Dominantes, Modos, Buscador).
- `api/cifra.js`, `api/artista.js` — servidorzinho (Vercel) que baixa a cifra.
- `sw.js` + `manifest.webmanifest` — instalar como app e abrir sem internet.

Hospedagem: Vercel (importar este repositório; não precisa configurar nada).
